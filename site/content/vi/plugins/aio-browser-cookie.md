# aio-browser-cookie

Trích xuất cookie trình duyệt bằng rookiepy và tái sử dụng cho các authenticated request hoặc export cookie định dạng Netscape.

## Cài đặt

```bash
/plugin install aio-browser-cookie@aiocean-plugins
```

## Skills

- Trích xuất cookie từ Chrome, Firefox và Safari
- Export ra JSON hoặc định dạng Netscape
- Tái sử dụng cookie cho các HTTP request đã authenticate

## Yêu cầu

- python3
- rookiepy
