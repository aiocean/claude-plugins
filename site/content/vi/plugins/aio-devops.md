# aio-devops

`v1.0.2`

Workflow cho GitHub, GitLab, và git worktree gói chung trong một toolkit — quản lý repo, PR, MR, pipeline, và parallel branch mà không phải nhảy giữa nhiều CLI.

## Cài đặt

```
/plugin install aio-devops@aiocean-plugins
```

## Skills (3)

- [**aio-github**](/vi/plugins/aio-devops/aio-github) — Quản lý GitHub repo, PR, và issue qua github-mcp (tự động cài nếu chưa có).
- [**aio-gitlab**](/vi/plugins/aio-devops/aio-gitlab) — Quản lý GitLab MR, pipeline, branch, và CI job qua gitlab-mcp (tự động cài nếu chưa có).
- [**aio-worktree**](/vi/plugins/aio-devops/aio-worktree) — Quản lý git worktree cho parallel development workflow — create, sync, và spotlight preview.
