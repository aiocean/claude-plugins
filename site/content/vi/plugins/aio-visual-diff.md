# aio-visual-diff

`v0.1.0`

Verify UI do AI build khớp với design qua diff đo lường — trích computed CSS và bounding box qua Chrome DevTools MCP, diff với Figma reference hoặc baseline đã đóng băng, đẩy delta số về cho agent. Không nhìn screenshot bằng mắt.

## Cài đặt

```
/plugin install aio-visual-diff@aiocean-plugins
```
