# Plugins cho Claude Code

**Skills, agents, và workflow** tái sử dụng được cho Claude Code. Mỗi plugin
bundle một hoặc nhiều skill tự kích hoạt khi gặp tác vụ tương ứng.

```
/plugin marketplace add aiocean/claude-plugins
/plugin install <plugin-name>@aiocean-plugins
```

Duyệt 28 plugin bên dưới — click vào plugin nào để xem chi tiết các skill của nó.
