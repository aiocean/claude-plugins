# aio-saas-tools

`v1.0.2`

Điều khiển Jira, Confluence, Google Workspace (Drive/Gmail/Calendar/Sheets/Docs), Tanca HR, và X/Twitter từ terminal — mỗi service một CLI, không phải chuyển context.

## Cài đặt

```
/plugin install aio-saas-tools@aiocean-plugins
```

## Skills (4)

- [**aio-atlassian**](/vi/plugins/aio-saas-tools/aio-atlassian) — Quản lý Jira issues, sprint, workflow và Confluence pages qua CLI.
- [**aio-google-workspace**](/vi/plugins/aio-saas-tools/aio-google-workspace) — Tương tác với các Google Workspace service (Gmail, Drive, Calendar, Sheets, Docs, Tasks) qua gws CLI.
- [**aio-tanca**](/vi/plugins/aio-saas-tools/aio-tanca) — Quản lý chấm công, ca làm và điểm danh nhân viên qua tanca-mcp (tự cài nếu thiếu).
- [**aio-x**](/vi/plugins/aio-saas-tools/aio-x) — Post, tìm kiếm và quản lý nội dung Twitter/X qua x-mcp (tự cài nếu thiếu).
