# aio-diagramming

`v1.0.2`

Tạo URL Mermaid có thể chia sẻ và tự động dựng diagram dashboard Grafana từ codebase — diagram dễ chia sẻ, không cần rời terminal.

## Cài đặt

```
/plugin install aio-diagramming@aiocean-plugins
```

## Skills (2)

- [**aio-grafana-diagram**](/vi/plugins/aio-diagramming/aio-grafana-diagram) — Tạo diagram Grafana để trực quan hóa hệ thống — phân tích codebase để tự động sinh diagram Mermaid kèm metric binding. Với diagram Mermaid độc lập, dùng…
- [**aio-mermaid**](/vi/plugins/aio-diagramming/aio-mermaid) — Tạo URL diagram Mermaid có thể chia sẻ (nén bằng LZ-String) cho flowchart, sequence, class, ER, state và gantt diagram.
