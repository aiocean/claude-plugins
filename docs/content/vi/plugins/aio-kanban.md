# aio-kanban

`v2.0.2`

Theo dõi công việc của AI agent trong một bảng kanban markdown commit vào repo — các cột Backlog, Todo, Doing, Done với WIP limit và auto-status khi bắt đầu session.

## Cài đặt

```
/plugin install aio-kanban@aiocean-plugins
```

## Skills (1)

- [**aio-kanban**](/vi/plugins/aio-kanban/aio-kanban) — Bảng kanban dạng markdown để quản lý task của AI agent — init, add, move, archive task qua các cột backlog/doing/done.
