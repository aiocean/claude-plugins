# aio-youtube

Search YouTube và extract transcript video dùng yt-dlp.

## Cài đặt

```bash
/plugin install aio-youtube@aiocean-plugins
```

## Làm gì

- Search YouTube video theo keyword hoặc topic
- Extract transcript từ bất kỳ video YouTube nào
- Tóm tắt nội dung video từ transcript

## Yêu cầu

- yt-dlp
- jq
- curl
