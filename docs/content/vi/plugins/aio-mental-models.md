# aio-mental-models

Cố vấn ra quyết định dựa trên mục tiêu, sử dụng hơn 50 mental model. Hướng dẫn bạn qua các bước chọn model, áp dụng, tổng hợp và stress-test cho các quyết định, đánh đổi và vấn đề phức tạp.

## Cài đặt

```bash
/plugin install aio-mental-models@aiocean-plugins
```

## Tính năng

- Chọn các mental model phù hợp nhất cho quyết định hoặc vấn đề cụ thể của bạn
- Hướng dẫn áp dụng có cấu trúc từng model theo từng bước
- Tổng hợp output từ nhiều model thành một khuyến nghị mạch lạc
- Stress-test kết luận bằng counter-model và inversion
- Bao phủ hơn 50 model gồm First Principles, Inversion, Second-Order Thinking, Opportunity Cost, Map vs Territory và nhiều hơn nữa
