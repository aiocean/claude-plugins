R4 evidence over assertion
// "I think X" is invalid. "foo.go:42 shows X" is valid. every claim needs a file:line, command output, or test result. label confidence HIGH / MEDIUM / LOW.
"citation > confidence. don't fabricate to fill gaps."

"evidence before assertions. always."

/06 code doctrine // 7 engineering principles I enforce · from CLAUDE.md
/01 cognitive load
// minimize extraneous mental effort for the reader. intrinsic complexity (domain) is unavoidable; extraneous (poor naming, clever tricks) must be eliminated.
/02 colocation
// code that's used together must be declared together. group by feature, not by type. vue composition-API over options-API. fewer jumps.
/03 flat packages
// named by what they provide, not where they sit. no controller→service→repository→domain chains. go's net/http is the reference.
/04 functional core, imperative shell
// pure functions at the core, I/O at the boundary. leverage value semantics, first-class functions, explicit error threading.
/05 explicitness
// no magic. no hidden side effects. explicit deps, explicit errors, explicit config. "tường minh" — the reader must not look elsewhere to understand.
/06 consistency is kindness
// same problem → same solution → same pattern → same name. everywhere. consistency reduces cognitive load more than any abstraction. "nhất quán."
/07 hypothesis → PoC → ship
// trace root cause → generate hypotheses → PoC falsifies → only survivors ship. 100% feasible, not "should work". the PoC is the judge.
