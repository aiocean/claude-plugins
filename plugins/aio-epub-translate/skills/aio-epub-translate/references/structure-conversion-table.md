# BẢNG CHUYỂN ĐỔI CẤU TRÚC NHANH

| Cấu trúc tiếng Anh | Cách chuyển sang tiếng Việt |
|---|---|
| It is... that... (cleft) | Chính... là..., hoặc bỏ cấu trúc nhấn mạnh, viết câu bình thường |
| There is/are... | [Nơi/Thời gian] + có... |
| Passive voice | Chuyển sang chủ động, hoặc dùng "được/bị" có chọn lọc |
| -ing participle clause | Tách thành câu riêng, hoặc dùng "đang/vừa" |
| Relative clause (who/which/that) | Tách thành câu riêng, hoặc dùng "mà" |
| If... would have... | Nếu... thì đã..., Giá mà... thì... |
| Not only... but also... | Không chỉ... mà còn..., Vừa... vừa... |
| The more... the more... | Càng... càng... |
| It takes [time] to... | Phải mất [thời gian] để..., [Thời gian] mới... |
| He is a man who... | Bỏ "là một người mà" — viết trực tiếp |
| She found herself unable to... | Cô không thể... / Cô nghẹn... |
| The fact that... | Việc... / Chuyện... |

# TỰ KIỂM TRA TRƯỚC KHI SUBMIT

Sau khi dịch xong mỗi batch, rà lại:

1. **Tín**: Đủ ý? Không thêm, không bớt? Tên riêng/số liệu chính xác?
2. **Đạt**: Có câu nào "nghe lạ", không phải cách người Việt nói? Có bị động thừa? Có cụm từ "sáo rỗng dịch thuật"?
3. **Nhã**: Nhịp chẵn? Vế cân đối? Có dùng từ láy, thành ngữ khi có thể? Câu ngắn tạo nhấn?
4. **Giọng văn**: Nhất quán? Đối thoại khác trần thuật? Cảm xúc nguyên tác còn nguyên?
5. **Phép thử cuối**: Che nguyên tác đi — bản dịch đọc được như tác phẩm viết bằng tiếng Việt không?
