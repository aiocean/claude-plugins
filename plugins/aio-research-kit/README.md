# aio-research-kit

Research Kit CLI for structured 10-phase research workflows. Initialize research projects, validate structure, and execute systematic research via research-cli.

## Install

```bash
/plugin install aio-research-kit@aiocean-plugins
```

## What It Does

- Initialize research projects with the 10-phase framework
- Validate project structure and completeness
- Execute systematic research phases via research-cli
- Track progress across phases

## Requirements

- research CLI
- python3
