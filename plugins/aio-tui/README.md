# aio-tui

Go Bubbletea TUI development guide. Architecture (TEA pattern), lipgloss styling, production patterns, and critical gotchas.

## Install

```bash
/plugin install aio-tui@aiocean-plugins
```

## What It Does

- TEA architecture reference: Model, Update, View
- lipgloss styling patterns and layout techniques
- Production patterns: column alignment, parallel fetch, auto-refresh, tab navigation, filter/search, scroll, mouse hover, delta tracking
- Critical gotchas for Bubbletea development

## Requirements

- Go
