# aio-feedback

Submit feedback, bug reports, and feature requests for aiocean plugins directly from Claude Code via GitHub Issues.

## Install

```bash
/plugin install aio-feedback@aiocean-plugins
```

## Skills

- Submit bug reports as GitHub Issues
- Submit feature requests
- Request new plugins
- All submissions go directly to the aiocean/claude-plugins repository

## Requirements

- gh CLI (GitHub CLI, authenticated)
