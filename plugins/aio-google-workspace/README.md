# aio-google-workspace

Google Workspace operations via gws CLI. Drive, Gmail, Calendar, Sheets, Docs, Tasks, and cross-service workflows.

## Install

```bash
/plugin install aio-google-workspace@aiocean-plugins
```

## What It Does

- Send emails via Gmail
- Upload and manage files in Google Drive
- Create and query Google Calendar events
- Read and write Google Sheets data
- Create and edit Google Docs
- Manage Google Tasks
- Generate standup reports from calendar and email data

## Requirements

- [gws CLI](https://github.com/nguyenvanduoc/gws) installed and authenticated
