# aio-debug

REACTIVE debugging — systematic debug & fix orchestrator for bugs, errors, and test failures. Four-phase pipeline: codebase context → root cause investigation → minimal fix → code review validation. Circuit breaker escalation after 3 failed attempts.

## Install

```bash
/plugin install aio-debug@aiocean-plugins
```

## Skills

- Phase 1: Codebase context gathering
- Phase 2: Root cause analysis
- Phase 3: Minimal fix implementation
- Phase 4: Code review validation
- Circuit breaker: escalates after 3 failed fix attempts

## Requirements

- git
