# aio-github

GitHub CLI for repository, PR, and issue management. List repos, manage pull requests, review code, and track issues via github-mcp.

## Install

```bash
/plugin install aio-github@aiocean-plugins
```

## Skills

- Repository management (list, clone, create)
- Pull request CRUD (create, update, merge, close)
- Issue tracking (create, comment, close, label)
- Code review via github-mcp

## Requirements

- Go
- github-mcp
- Environment: `GITHUB_TOKEN`
