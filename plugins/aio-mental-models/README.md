# aio-mental-models

Objective-driven decision advisor using 50+ mental models. Guides you through model selection, application, synthesis, and stress-testing for decisions, trade-offs, and complex problems.

## Install

```bash
/plugin install aio-mental-models@aiocean-plugins
```

## What It Does

- Selects the most relevant mental models for your specific decision or problem
- Guides structured application of each model step by step
- Synthesizes outputs across multiple models into a coherent recommendation
- Stress-tests conclusions by applying counter-models and inversion
- Covers 50+ models including First Principles, Inversion, Second-Order Thinking, Opportunity Cost, Map vs Territory, and more
