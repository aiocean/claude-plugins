# aio-neobrutalism

Neobrutalism design system bootstrapper. Detects tech stack, generates CSS tokens, and transforms existing UI components with bold borders, hard shadows, vibrant colors.

## Install

```bash
/plugin install aio-neobrutalism@aiocean-plugins
```

## What It Does

- Detects your frontend tech stack automatically
- Generates CSS custom property tokens for the neobrutalism design system
- Transforms existing components to use bold borders, hard box shadows, and vibrant accent colors
- Provides component patterns and usage examples

## Supported Stacks

React, Vue, Svelte, Next.js, Tailwind CSS, plain HTML/CSS
