# aio-x

X/Twitter CLI for tweet management, user interactions, engagement, moderation, and list operations via x-mcp.

## Install

```bash
/plugin install aio-x@aiocean-plugins
```

## What It Does

- Post tweets and threads
- Search tweets and users
- Manage mentions and timeline
- Engagement and moderation actions
- List operations

## Requirements

- Go
- x-mcp
- `X_API_KEY`, `X_API_SECRET`, `X_ACCESS_TOKEN` environment variables
