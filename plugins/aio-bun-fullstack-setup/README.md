# aio-bun-fullstack-setup

Scaffold and setup Bun fullstack projects. Scaffold mode detects existing files and generates only what is missing. Single port API + static frontend with Vite proxy in dev.

## Install

```bash
/plugin install aio-bun-fullstack-setup@aiocean-plugins
```

## Skills

- Project scaffolding with missing-file detection
- Single port server setup (API + static frontend)
- Vite proxy configuration for development
- Docker setup for production

## Requirements

- bun
