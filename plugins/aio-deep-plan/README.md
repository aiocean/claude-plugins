# aio-deep-plan

PROACTIVE planning toolkit — use before writing code to understand codebase structure and plan changes. Five skills: discover, map, snapshot, plan, review.

## Install

```bash
/plugin install aio-deep-plan@aiocean-plugins
```

## Skills

- `discover`: find relevant code and entry points
- `map`: structural analysis of modules and dependencies
- `snapshot`: baseline the current state before changes
- `plan`: generate an implementation plan
- `review`: post-implementation review against the plan

## Requirements

- GitNexus
- LSP
