# aio-monitoring-observability

Monitoring and observability strategy, implementation, and troubleshooting. Metrics design (Golden Signals, RED/USE), distributed tracing (OpenTelemetry), alerting, SLOs, dashboards, log aggregation, and tool selection.

## Install

```bash
/plugin install aio-monitoring-observability@aiocean-plugins
```

## What It Does

- Design metrics using Golden Signals (latency, traffic, errors, saturation), RED, and USE methods
- Plan and implement distributed tracing with OpenTelemetry
- Define SLOs and error budgets
- Design alerting rules that reduce noise
- Architect log aggregation pipelines
- Select and compare observability tooling (Prometheus, Grafana, Jaeger, Loki, etc.)
- 7 automation scripts for common observability tasks

## Requirements

- python3
