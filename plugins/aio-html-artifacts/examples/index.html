What each file is for

The corpus is six files: four artifacts at full tier, one per genre, a fifth in the report genre at tier= brief, and this index. The kind column is the value --kind accepts for that file; the grep column is the structure the validator fails that kind without.

What to reuse, and what to regenerate

The only motion in this file

One transition, 150ms, on two named properties, on state changes only, and it starts off. A gallery is the one genre where motion is the content, so the control that starts it sits under the reader's hand — a checkbox and a :has() selector, which is why this file ships zero JavaScript and the control still works. 150ms is long enough to read as a change and short enough to stay out of the way, and naming the two properties keeps the work off layout and paint, which transition: all cannot promise on a table of links.
