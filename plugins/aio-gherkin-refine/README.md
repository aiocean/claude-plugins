# aio-gherkin-refine

Comprehensive BDD field guide — writes and reviews Gherkin with expert quality. Includes Example Mapping, 3 Amigos, anti-patterns catalog, and declarative style guide.

## Install

```bash
/plugin install aio-gherkin-refine@aiocean-plugins
```

## Skills

- Write mode: draft well-structured Gherkin scenarios from requirements
- Review mode: audit existing Gherkin for anti-patterns and style issues
- Example Mapping: break down user stories into rules and examples
- 3 Amigos facilitation guidance
- Anti-patterns catalog with declarative style enforcement
