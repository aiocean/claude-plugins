# aio-worktree

Manage git worktrees for parallel development. Create worktrees, sync changes (spotlight), merge branches, and cleanup.

## Install

```bash
/plugin install aio-worktree@aiocean-plugins
```

## What It Does

- Create worktrees: spin up isolated branches for parallel work
- Spotlight: preview and sync changes between worktrees
- Merge: bring worktree changes back to the main branch
- Cleanup: remove stale worktrees and their branches

## Requirements

- git
