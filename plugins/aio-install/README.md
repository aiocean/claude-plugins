# aio-install

Install aiocean plugins into the current project's settings.local.json. List available plugins, enable/disable them.

## Install

```bash
/plugin install aio-install@aiocean-plugins
```

## What It Does

- List all available aiocean plugins with descriptions
- Install and enable plugins into the current project
- Disable or remove plugins from the current project
- Manages plugin state via `.claude/settings.local.json`
