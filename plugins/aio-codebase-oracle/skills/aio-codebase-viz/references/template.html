Conventions
Event-Driven Architecture — All components communicate via typed event bus. Use EventHelpers.safeEmit() and safeListen().
Lazy Loading — Monaco Editor dynamically imported to reduce initial bundle size.
Debounced Updates — Preview updates debounced 250ms to avoid excessive re-renders.
State Compression — Diagram state compressed with LZ-String for URL sharing.
LocalStorage Persistence — API keys and preferences stored client-side only.
Gotchas
!No Backend — All AI calls made directly from browser. API keys exposed in client storage.
!Mermaid v11 Only — System prompt enforces v11 syntax. Older syntax will fail.
!Dynamic Import — Monaco must be imported before any editor operations.
!Liveblocks Optional — Collaboration only works if VITE_LIVEBLOCKS_PUBLIC_API_KEY is configured.
!URL Hash Limits — Very large diagrams may exceed URL length limits.
