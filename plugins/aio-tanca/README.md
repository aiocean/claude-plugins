# aio-tanca

Tanca CLI for employee timekeeping and HR operations. Manage employees, shifts, check-in/check-out, and clock logs via tanca-mcp.

## Install

```bash
/plugin install aio-tanca@aiocean-plugins
```

## What It Does

- Employee management: list, create, update records
- Shift management: assign and view shift schedules
- Check-in / check-out: record and query attendance
- Clock logs: view and export timekeeping history

## Requirements

- Go
- tanca-mcp
- `TANCA_TOKEN` environment variable
