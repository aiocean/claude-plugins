# aio-uiux

Comprehensive UI/UX design knowledge base covering visual design, typography, color theory, layout, accessibility, UX psychology, interaction design, motion/animation, component patterns, design systems, UX writing, performance UX, modern CSS, and responsive design.

## Install

```bash
/plugin install aio-uiux@aiocean-plugins
```

## What It Does

- Visual design principles and typography guidelines
- Color theory and accessible color usage (WCAG compliance)
- UX psychology and interaction design patterns
- Motion and animation best practices
- Component patterns and design system conventions
- UX writing and microcopy guidance
- Performance UX and modern CSS techniques
- Responsive and adaptive design strategies

100+ topics with semantic search across all categories.
